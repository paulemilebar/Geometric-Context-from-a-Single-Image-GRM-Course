# Geometric Context from a Single Image

Project for the Graphical Models course (MVA & CentraleSupélec).
We reproduce and extend the method from Hoiem, Efros and Hebert (ICCV 2005),
which estimates the coarse 3D geometric structure of outdoor scenes from a single image.

The task is to classify each pixel of an image into one of three geometric classes:
ground, vertical surfaces, and sky. Beyond the original AdaBoost classifier from the
paper, we also implement Belief Propagation and a Graph Neural Network as alternative
inference methods, and apply the resulting geometric context to improve face detection.

## Dataset

We use the dataset released by the authors, available at
https://dhoiem.cs.illinois.edu/projects/data.html

It contains 300 outdoor images collected from Google Image Search, covering a wide
variety of natural, suburban and urban scenes. All ground truth annotations are stored
in a single file `allimsegs2.mat`, which contains for each image the superpixel
segmentation used by the authors (`segimage`) and the geometric label of each
superpixel (`vert_labels`: 1=ground, 2=vertical, 3=sky).

A second file `rand_indices.mat` provides the official split:
- `cluster_images`: 50 images used to train the segmentation algorithm
- `cv_images`: 250 images used for 5-fold cross-validation of the full system

## Steps completed

### Step 1: dataset loading

`src/dataset.py` implements `HoiemDataset`, which parses `allimsegs2.mat` and
exposes each image as a triplet `(image, label_map, meta)`. The label map is
reconstructed from the per-superpixel labels in the .mat file. The class also
handles the official train/test split from `rand_indices.mat`.

### Step 2: superpixel segmentation

`src/superpixels.py` and `02_superpixels.py` apply the Felzenszwalb-Huttenlocher
graph-based segmentation algorithm to group pixels into superpixels, following the
parameters used in the original paper (scale=100, sigma=0.8, min_size=100).

Each superpixel is assumed to correspond to a single geometric label. The adjacency
matrix between superpixels is computed at this step and stored alongside the
segmentation, as it is needed later for Belief Propagation and the GNN.

Results on the 300 images:
- mean boundary recall: 0.893 (superpixels respect semantic boundaries well)
- mean number of superpixels per image: 633

### Step 3: feature extraction

`03_features.py` implements the 78-dimensional feature vector described in Table 1
of the paper, computed for each superpixel independently.

The four feature groups are:

**Color (16 features)**: mean RGB, mean HSV, hue histogram (5 bins + entropy),
saturation histogram (3 bins + entropy). These allow the model to capture the
relationship between surface material and 3D orientation implicitly.

**Texture (15 features)**: responses of 12 DOOG filters (Difference of Offset
Gaussians) at 12 orientations from 0 to 165 degrees, plus mean, dominant orientation
(argmax), and contrast (max minus median). DOOG filters capture directional texture
gradients, which are informative about surface orientation.

**Location and shape (12 features)**: normalized x/y position, 10th and 90th
percentiles of x and y, position relative to the estimated horizon, and shape
descriptors from the convex hull (number of sides, compacity, contiguity).

**Geometry (35 features)**: statistics of long straight lines detected via Hough
transform and their pairwise intersections, binned by orientation and distance from
the image center. These features give the model indirect access to vanishing point
information without computing it explicitly.

Features are computed once and cached in `data/features/` to avoid recomputing
them at each training run.

### Step 4: AdaBoost classification

`04_adaboost.py` implements the baseline classifier using the 78 features extracted previously. We use an AdaBoost model with 200 decision trees of depth 3 (approximately 8 leaf nodes), as suggested in the original paper. 

This model treats each superpixel independently. It achieves about 83% pixel accuracy, which is a solid baseline but lacks spatial consistency since it does not consider the relationship between neighboring superpixels.

### Step 4b: Multi-Hypothesis classification (MultiH)

`04b_multiH_classify.py` implements the more advanced pipeline from the 2005 paper. Instead of relying on a single segmentation, we generate multiple segmentation hypotheses (different levels of detail).

The method trains:
1. A **label classifier** to predict the geometric class of a region.
2. A **homogeneity classifier** to estimate if a region is likely to contain only one geometric class.

Predictions from all hypotheses are fused to produce the final labels. This approach is more robust to segmentation errors and improves accuracy to nearly 86%, matching the results reported in the paper.

### Step 5: Graph Neural Network (GNN)

`05_gnn.py` and its variants (up to `05d_gnn_improved_multiH.py`) explore modern deep learning approaches. We use a **Graph Attention Network (GAT)** to model the superpixel graph. 

The GNN allows superpixels to "communicate" with their neighbors, enabling the model to learn spatial context. The improved version (`05d`) also incorporates the class probabilities from the MultiH model as additional features, further boosting performance by combining classical and modern techniques.

### Step 6: Belief Propagation (BP)

`06a_belief_propagation.py` implements a classic Graphical Model approach. We define a Conditional Random Field (CRF) over the superpixel graph. 

The model uses:
- **Unary potentials**: Based on the AdaBoost or MultiH probabilities.
- **Pairwise potentials**: Encouraging neighboring superpixels with similar colors or positions to have the same label.

We use the max-product algorithm (Belief Propagation) to find the most likely assignment of labels. This method effectively smoothes the results and removes isolated classification errors.

## Requirements

```
pip install -r requirements.txt
```

Main dependencies: numpy, scipy, opencv-python, scikit-image, matplotlib, tqdm, torch.

## Usage

Run the scripts in order to reproduce the full pipeline:

1. **Preprocessing**:
   ```bash
   python 01_explore_dataset.py
   python 02_superpixels.py
   python 03_features.py
   python 03b_segmentation_hypotheses.py
   ```

2. **Classification & Inference**:
   - **Baseline**: `python 04_adaboost.py`
   - **Paper Pipeline**: `python 04b_multiH_classify.py`
   - **GNN Approach**: `python 05d_gnn_improved_multiH.py`
   - **CRF/BP Approach**: `python 06a_belief_propagation.py`
